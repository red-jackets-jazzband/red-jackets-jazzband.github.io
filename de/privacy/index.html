Datenschutz

Verantwortlich

Verantwortlich für die auf dieser Seite beschriebenen Daten ist die Red Jackets Jazzband. Fragen, Löschwünsche oder Beschwerden: info@redjackets.nl. Wir antworten innerhalb eines Monats.

Diese Website besuchen

Die Seiten, Songs und Setlists sind einfache Dateien. Sie müssen sich nicht anmelden, und wir setzen keine Tracking-Cookies. Ihre Setlists, Songversionen und Einstellungen bleiben im eigenen Browser (lokaler Speicher) und verlassen Ihr Gerät nicht, es sei denn, Sie schalten unten Geräte verbinden ein.

Manche Seiten binden Videos oder Musik von YouTube, Spotify oder SoundCloud ein. Beim Abspielen geht Ihre Anfrage an diesen Dienst, es gilt dessen eigene Datenschutzerklärung.

Geräte verbinden (optional)

Geräte verbinden hält Ihre persönlichen Setlists und eigenen Songversionen auf Handy, Tablet und Computer gleich. Die Funktion ist aus, bis Sie auf Dieses Gerät verbinden tippen, mit einem Code auf Beitreten tippen oder einen geöffneten Kopplungslink bestätigen. Geteilte Räume (der Tab Geteilt) sind eine eigene, freiwillige Funktion, die genauso funktioniert: Sie starten einen Raum oder treten einem bei, unter einem Namen Ihrer Wahl, und die Songversionen und Setlists, die Sie dort ablegen, sind unter diesem Namen für alle sichtbar, die den Code des Raums haben. Bis Sie eines davon tun, sendet die Website nichts an den Synchronisierungsserver.

  • Was gespeichert wird. Ihre Daten werden im Browser mit einem Schlüssel verschlüsselt, der aus Ihrem Sync-Code entsteht. Der Server speichert nur die verschlüsselten Daten, eine Versionsnummer und eine aus dem Code abgeleitete Kennung. Wir können Ihre Setlists nicht lesen, und der Code erreicht den Server nie.
  • Wo. Auf einem Server der Cloudflare, Inc., die die Daten in unserem Auftrag verarbeitet.
  • IP-Adressen. Um Missbrauch zu begrenzen, zählt der Server, wie viele Sync-Kopien von einer Adresse angelegt werden. Dafür speichert er nur einen Hash Ihrer IP-Adresse, vermischt mit einem täglich wechselnden Salt, und löscht ihn nach einem Tag. Cloudflare selbst kann Ihre IP-Adresse bei der Verarbeitung der Anfrage ebenfalls sehen, wie jeder Webhoster.
  • Cookies und Konten. Keine. Wer Ihren Sync-Code kennt, kann Ihre synchronisierten Daten lesen und ändern. Halten Sie ihn deshalb privat.
  • Wie lange. Eine Sync-Kopie, die 18 Monate nicht aktualisiert wurde, wird automatisch gelöscht.
  • Löschen. Tippen Sie im Dialog auf Serverkopie löschen (bei einem geteilten Raum im Tab Geteilt). Ihre Daten auf Ihren Geräten bleiben erhalten; Trennen beendet die Synchronisierung auf einem Gerät.

Ihre Einstellungen (Instrument, Tempo, Bedienfelder) werden nicht synchronisiert.

Ihre Rechte

Sie können Auskunft, Berichtigung oder Löschung Ihrer Daten verlangen und sich bei der niederländischen Datenschutzbehörde (Autoriteit Persoonsgegevens) beschweren. Da die synchronisierten Daten verschlüsselt sind und der Code uns nie erreicht, können wir Ihre Kopie weder finden noch lesen. Bitte schicken Sie uns Ihren Sync-Code nicht: Wer ihn liest, kommt an Ihre Daten. Nutzen Sie Serverkopie löschen oder lassen Sie die Kopie nach 18 Monaten ablaufen.
