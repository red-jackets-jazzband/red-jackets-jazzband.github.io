Privacy

Wie is verantwoordelijk

Red Jackets Jazzband is verantwoordelijk voor de gegevens die op deze pagina worden beschreven. Vragen, verzoeken om gegevens te verwijderen of klachten: info@redjackets.nl. We antwoorden binnen een maand.

Deze site bekijken

De pagina’s, songs en setlists zijn gewone bestanden. Je hoeft niet in te loggen en we plaatsen geen trackingcookies. Je setlists, songversies en instellingen blijven in je eigen browser (lokale opslag) en verlaten je apparaat niet, tenzij je hieronder Apparaten koppelen aanzet.

Sommige pagina’s tonen video’s of muziek van YouTube, Spotify of SoundCloud. Als je er een afspeelt, gaat je verzoek naar die dienst, met haar eigen privacybeleid.

Apparaten koppelen (optioneel)

Met Apparaten koppelen blijven je persoonlijke setlists en je eigen songversies hetzelfde op je telefoon, tablet en computer. Het staat uit totdat je op Dit apparaat koppelen drukt, op Meedoen met een code, of een koppellink bevestigt die je opende. Gedeelde ruimtes (het tabblad Gedeeld) zijn een aparte, vrijwillige keuze die op dezelfde manier werkt: je start of neemt deel aan een ruimte met een naam naar keuze, en de songversies en setlists die je daar neerzet zijn onder die naam zichtbaar voor iedereen met de code van de ruimte. Als je apparaten gekoppeld zijn, blijven ook de gedeelde ruimtes waarin je zit (de code van elke ruimte, de naam die je eraan gaf en je weergavenaam daar) op al je apparaten gelijk, net zo versleuteld als de rest; een apparaat dat je koppelt neemt dus ook deel aan die ruimtes, en een ruimte verlaten op één apparaat betekent hem verlaten op de andere. Tot je een van beide doet stuurt de site niets naar de synchronisatieserver.

  • Wat wordt opgeslagen. Je gegevens worden in je browser versleuteld met een sleutel die uit je synchronisatiecode komt. De server bewaart alleen de versleutelde gegevens, een versienummer en een identificatie die uit de code is afgeleid. We kunnen je setlists niet lezen, en de code komt nooit op de server.
  • Waar. Op een server van Cloudflare, Inc., die de gegevens namens ons verwerkt.
  • IP-adressen. Om misbruik tegen te gaan telt de server hoeveel synchronisatiekopieën vanaf één adres worden aangemaakt. Daarvoor bewaart hij alleen een hash van je IP-adres, gemengd met een dagelijks wisselend zout, en verwijdert die na een dag. Cloudflare zelf kan je IP-adres ook zien terwijl het het verzoek afhandelt, zoals elke webhost.
  • Cookies en accounts. Geen. Wie je synchronisatiecode heeft, kan je gesynchroniseerde gegevens lezen en wijzigen. Houd de code dus privé.
  • Hoe lang. Een synchronisatiekopie die 18 maanden niet is bijgewerkt, wordt automatisch verwijderd.
  • Verwijderen. Druk in het dialoogvenster op Serverkopie verwijderen (bij een gedeelde ruimte op het tabblad Gedeeld). Je gegevens op je apparaten blijven staan; met Ontkoppelen stopt het synchroniseren op een apparaat.

Je voorkeuren (instrument, tempo, panelen) worden niet gesynchroniseerd.

Je rechten

Je kunt ons vragen om inzage in, correctie of verwijdering van je gegevens, en je kunt een klacht indienen bij de Autoriteit Persoonsgegevens. Omdat de gesynchroniseerde gegevens versleuteld zijn en de code ons nooit bereikt, kunnen we je kopie niet vinden of lezen. Stuur ons je synchronisatiecode dus niet: wie hem leest, kan bij je gegevens. Gebruik Serverkopie verwijderen, of laat de kopie na 18 maanden vanzelf verlopen.
